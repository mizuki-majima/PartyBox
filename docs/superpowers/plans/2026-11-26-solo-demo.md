# 通常のゲームを「1人で試す」 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 通常のゲームで、全員ぶんの画面を1ページ（`/demo/<ゲーム>`）に並べ、1人で最初から最後まで遊べるようにする。

**Architecture:** 懇親会のデモの仕組み（iframe を並べ、枠ごとに `?seat=` で別の人として動かす）を通常のゲームに広げる。サーバーは `room:create` の `demo: true` を通常のゲームでも受け付ける（使い捨て・保存しない・勝者の記録に残さない、は今のデモと同じ）。画面は `/demo/:gameId` で、懇親会なら今のデモ、通常のゲームなら新しい `GameDemo` を出す。

**Tech Stack:** TypeScript（strict）、React 19・React Router、Socket.IO、Vitest、Playwright。

**Spec:** `docs/superpowers/specs/2026-11-26-solo-demo-design.md`

## Global Constraints

- 対象は通常のゲーム（`GAMES`: whose-answer・unanimous・liar・grow-answer・ten-sec-trial・ad-dodge）。懇親会のデモは今のまま（本番で常設のルームがあると作れない、も変えない）。プロンプト・グランプリは対象外
- 人数は「そのゲームの最少人数〜6人」。既定は 4人（範囲に無ければ範囲の中でいちばん近い数）
- ロビーから始める（自動で開始しない）。人数を変える・「最初からやり直す」はルームを作り直す
- 入口は「ルームを作る」画面（`/play/<ゲーム>`）だけ。トップのカードには足さない
- デモのルームの結果は勝者の記録に残さない
- 常設のルーム（`room.json`）があっても、通常のゲームのデモは作れる
- 画面の文言は日本語、短く平易に。色・角丸を直接書かず、既存の部品（`Button` `Card` `Icon`）とトークンを使う（CLAUDE.md）
- E2E は `data-testid` で掴む

## Review Focus

1. デモを作る途中で、参加者のソケットを閉じてから iframe が入り直すまでの間に、ホストが「切断30秒」で別の人に移らないこと（枠は数秒で入り直す。移った場合はホストの枠でスタートできなくなる）→ Task 3 の E2E で、ホストの枠に「スタート」が出ることを確かめる
2. 「最初からやり直す」・人数の変更を続けて押しても、ルームが2つ同時にできて枠が古いルームを見続けないこと → Task 3 の E2E で、人数を変えたあとホストの枠の人数が新しい数になることを確かめる
3. 本番（常設のルームあり）で通常のゲームのデモが作れること → Task 1 の試験
4. デモで「もう一回」を押して2回目を最後まで遊んでも、勝者の記録に残らないこと（`room.demo` はルームに付くので、もう一回でも残らない）→ Task 1 の試験は1回目だけ見る。2回目は同じ判定を通るので、試験は足さない
5. 狭い画面（スマホ）でデモを開いたとき、枠が縦に並んで操作できること → Task 3 で、枠の並びを1列に折り返す（試験はしない。PC 向けと文言で案内する）

**Interfaces:**

- Produces（`client/lib/soloDemo.ts`）:

  - `soloCounts(meta: { minPlayers: number; maxPlayers: number }): number[]` … 最少人数〜`min(6, maxPlayers)`
  - `soloDefault(meta: { minPlayers: number; maxPlayers: number }): number` … 4 を `soloCounts` の範囲に収めた数
  - `soloName(n: number): string` … `` `プレイヤー${n}` ``（n は 1 始まり。1 がホスト）

  - `interface SoloDemoRoom { code: string; players: number }`
  - `createSoloDemoRoom(gameId: GameId, players: number): Promise<SoloDemoRoom>` … `soloName(1)` で `demo: true` のルームを作り、`soloName(2..players)` を参加させ、各セッションを `soloSeat(n)` の枠に保存してからソケットを閉じる。**開始はしない**
  - `closeSoloDemoRoom(room: SoloDemoRoom): Promise<void>` … ホストの枠のセッションで入り直して `room:close`。失敗しても気にしない。全部の枠のセッションを消す

  await page.setViewportSize({ width: 1600, height: 1000 });

  for (let n = 1; n <= 4; n++) {
    await expect(frame(n).getByTestId('player-count')).toHaveText('4', { timeout: 20_000 });
    await expect(frame(n).getByTestId('demo-badge')).toBeVisible();

  await expect(frame(1).getByTestId('start-game')).toBeVisible(); // 1枚目がホスト

  await frame(1).getByRole('button', { name: '1ラウンド' }).click();
