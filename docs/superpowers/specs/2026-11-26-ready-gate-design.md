# 準備OKを待ってから進む（設計メモ）

2026-11-26。ユーザーの依頼と回答から。

## 目的

ゲーム開始のあと、遊び方が出てから次に進むのが早い（4秒）。説明を読む画面も時間で進む（嘘つきの役割確認 15秒、10秒裁判の事件と役職 30秒）。
時間で進めず、**全員が「準備OK」を押してから進む**ようにする。各ラウンドの始まりも同じにし、ラウンドの頭で嫌になったらやめられるようにする。

ユーザーの言葉: 「いったん準備完了を待つ段階を挟んでください。スタートボタンを押したらカウントダウンが始まり、必要であれば止められるような形に」「説明時間なども…みんなが準備OKを押すまで進まないように」「各ラウンドも同じ仕組みにして。各ラウンドの頭で嫌になったら戻れる/終了できるように」

## 決めたこと（ユーザーの回答）

- 準備の画面（以下「準備の関門」）: 全員が「準備OK」を押すと、**自動で**カウントダウン（3・2・1）が始まり、終わると進む。カウントダウン中はホストが「止める」で準備の画面に戻せる
- 準備の関門を置く所:
  - ゲーム開始の遊び方（全ゲーム。今の4秒の演出の代わり）
  - 嘘つきの役割確認（毎ラウンド。今の 15秒をやめる）
  - 10秒裁判の事件と役職（毎件。今の 30秒をやめる）
  - 各ラウンドの始まり（誰の答え・全員一致・広告をすり抜けろ！の「ROUND n」。今の 3秒をやめる）
- ラウンドの頭（2ラウンド目から）で、ホストは「ロビーに戻る」と「ここで終了」を選べる
  - ロビーに戻る: 今の `room:backToLobby` のまま（結果を出さず、記録にも残さない）
  - ここで終了: それまでに終わったラウンドの点で最終結果を出し、**勝者の記録に残す**。1ラウンドも終わっていなければ出さない
- 10秒裁判はトップの一覧とロビーの「ゲーム変更」から隠す（作りは残し、URL を直接開けば遊べる）
- 懇親会のデモの仮名に、本番の名前を一部にでも含むものを使わない（本番の名簿が名字だけの書き方で、仮名の一部と同じ字になっていた）

## 私が決めたこと（ユーザーが直せる）

- 切れている人（スマホが消えている人）は待たない。その人のせいで止まらないように
- 画面はついているのに押さない人がいて進めないときのため、ホストに「待たずに始める」（ゲーム開始）・「待たずに進む」（それ以外）を残す。押すとすぐカウントダウンに入る（今の「すぐに始める」の置き換え）
- 「止める」と、全員の準備OKを取り消す（止めた理由の人も含め、もう一度全員が押すと始まる）
- 1ラウンド目の「ROUND 1」は、ゲーム開始の関門のすぐあとなので、関門にしない（2回続けて準備OKを押させない）。今までどおり短く出して進む
- 嘘つき・10秒裁判は、ラウンドの頭が役割確認・事件の説明なので、そこに「ロビーに戻る」「ここで終了」を出す（2ラウンド目・2件目から）
- 回答を育てろは、ラウンドの区切りが無い（絵と説明を順に回す）ので、ゲーム開始の関門だけ
- 「ロビーに戻る」は、ゲーム開始の関門にも出す（始める前に嫌になったとき）
- カウントダウンは 3秒（試験ではルームの時間の倍率で縮む）

## やらないこと

- 懇親会（司会が進行する企画）は変えない
- 各ゲームの答える時間・話す時間・投票の時間は変えない（時間で進むのが遊びの一部のため）
